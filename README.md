# Dokter Jaga — MedCalc V2

Website kalkulator medis mobile-first untuk Dokter Jaga.

## Fitur
- 12 kalkulator klinis pada rilis awal website
- pencarian dan filter kategori
- riwayat 10 hasil terakhir via localStorage
- responsive/mobile-first
- berjalan tanpa backend

## Deploy
Repo ini dapat langsung dideploy sebagai static site ke Vercel.

> Catatan: hasil kalkulator adalah alat bantu dan harus diverifikasi terhadap konteks klinis, satuan input, dan guideline yang berlaku.
